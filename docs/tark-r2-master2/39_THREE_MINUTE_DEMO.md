# 39 — Three-minute demonstration

A scripted demonstration plan, not a claim the R2 system is already built. Each panel/clip identifies REAL, SIMULATION or REPLAY and maturity. Select the path matching completed gates. Present-phase version keeps traction DISABLED_PHASE_1; never imitate real movement using an unlabeled animation.

## Primary 180-second sequence

| Time | Demonstration | Evidence/action | Honest fallback |
|---|---|---|---|
| 0–20 s | Problem and system | State/phase/source banner; explain forward sensors, position and uncertainty | Architecture illustration labelled DESIGN |
| 20–40 s | Vehicle and mine-course map | Qualified course position/route, or labelled replay | India overview if no fix; never fake location |
| 40–60 s | Visibility condition | Clear versus permitted controlled artificial-aerosol reference | Recorded labelled run with conditions, not invented live fog |
| 60–80 s | Evidence disagreement | RGB quality loss plus independently acquired radar/thermal support where actual data exists | Deterministic fixture labelled SIMULATION |
| 80–105 s | Approaching hazard | Range/relative-motion validity, TTC and reason; unavailable values remain unavailable | Recorded known scenario; no person in motor path |
| 105–125 s | Operating envelope | Show input assumptions, UNKNOWN when coverage unqualified, phase cap zero | Shadow calculation clearly PARAMETERIZED |
| 125–145 s | Fault and endpoint | Stale-source injection in simulation, expiry/zero-output evidence | Host-test evidence, not physical watchdog claim |
| 145–170 s | Blind curve | Two qualified physical peers if ready; occupancy intervals and stale-peer challenge | Two-node simulation clearly labelled, no fake physical peer |
| 170–180 s | Explainability | Open incident and show original reason/evidence/replay scope | One concise limitations card |

Do not squeeze unsafe aerosol operation or wiring changes into a timed stage performance. Pre-stage only completed/approved tests. If a separately released moving model exists, replace a segment with restrained low-energy response; do not call it HEMM braking. The default script needs no positive motor authority.

## Extended technical demonstration

Add 5–10 minutes outside the primary slot for raw/normalized provenance, calibration residuals, native thermal/FFC, valid-empty versus missing radar, ambiguous map matching, base loss, wrong-session/CRC rejection, clock errors, full-session replay mismatch/corruption, resource limits and physical cutoff evidence only if independently commissioned.

Judges should leave knowing what was observed, how old it was, why capability changed and what remains unvalidated. No prerecorded scene is presented as live; no separate bench/model tests are edited to imply one integrated physical run.
